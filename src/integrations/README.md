# AI Ecosystem Integration Layer

This layer keeps the project Node.js-native while adopting compatible patterns from open-source AI projects.

## Multi-AI
- CrewAI — roles/flows
- LangGraph — stateful graph orchestration
- Microsoft Agent Framework — handoffs/workflows
- CAMEL — communicating agent societies
- MetaGPT — software-team SOPs
- ChatDev — virtual software company

## Evaluation / test
- Promptfoo — evals/red teaming
- DeepEval — agent trajectory and quality metrics
- Inspect AI — controlled evaluations
- TruLens — feedback/evaluation
- ARES — RAG evaluation
- OpenAI Evals — benchmark/regression patterns

## Token/context optimization
- Headroom — context compression/shared context
- LLMLingua — prompt compression
- LongLLMLingua — long-context compression
- LLMLingua-2 — task-agnostic compression
- GPTCache — semantic caching pattern
- DSPy — metric-driven prompt/program optimization

## Human-like / memory
- Mem0 — personalized persistent memory
- Letta — stateful identity and memory
- Zep — temporal memory/knowledge graphs
- Graphiti — temporal knowledge graph
- Hindsight — retain/recall/reflect
- LangMem — long-term memory tools

## Discord management
- discord.js — runtime/API
- Jeeves — moderation/cases/automod patterns
- Red-DiscordBot — modular admin/moderation
- Modmail Bot — private support/modmail
- Assist — dashboard/moderation/automod patterns
- Disnake — event/rate-limit patterns

Important: these are integrated as Node-compatible architecture/adapters, not 25 separate runtimes. Python-only/full-runtime projects should be deployed as optional sidecars if their real SDK is later required.
